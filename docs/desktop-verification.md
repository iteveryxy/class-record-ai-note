## 安装与覆盖验证

完整生命周期检查由 `scripts/installer-smoke.ps1` 在项目临时目录执行。与开发运行、单独程序启动分开验证，不把构建成功等同于安装成功。

最终检查于 22:53 完成，结果全部通过，记录在 `artifacts/runtime/installer-smoke-result.json`：安装、覆盖重装、卸载、业务数据库行与密钥保留，注册表登记与程序文件清理。测试安装路径位于 D 盘的深层目录，而 Windows TEMP 位于 C 盘。录音、转录、笔记、历史和设置均作了逻辑逐行比较；没有只凭界面数量判断保留成功。测试结束后仅留下测试资料，没有保留测试安装登记。

此前复测发现深层 Python 文件路径和旧安装目录占用会导致覆盖时的卸载错误。安装器现先释放目录占用，在同一磁盘暂存整个旧程序，并使用 Windows 扩展路径删除深层依赖。程序运行时不会强制终止它来完成安装，要求用户先保存并退出。修复后的实际覆盖和卸载检查均无旧文件残留。
