# 课记 0.2.2 · 长课堂笔记修复

## 修复的问题

旧版提取完各段知识后，会反复将摘要切开再合并。如果模型生成的摘要没有持续缩短，八轮后就会提示「分段摘要过长，无法安全合并」。这属于知识整理阶段，原始转录通常已经成功。

现在长课堂逐段提取后按授课顺序组装，每段知识、公式、代码块和时间来源保持完整。全部分段能放进一次请求时，至多做一次全文合并；合并回答过长或达到输出限制时使用已有的完整分段笔记。系统不再要求长课堂反复压缩到一个模型上下文中。

- 每段提取完成后立即保存 `SUMMARY_PART`，模型 HTTP 原始响应仍保留。
- 删除每段「本段未提及」等空分类占位，减少重复内容；保留所有实际讲解的知识。
- 单篇笔记生成和人工编辑上限统一提升至 **200 万字符**。超过上限时，完整生成文档仍保存到原始结果中，不截断课堂末尾。
- 单段提取发生截断时仍报错，避免把不完整知识当作成功结果。网络、鉴权和其他模型错误也继续明确上报。
- 笔记版本检查继续生效，整理过程中产生的人工编辑不会被覆盖。

## 如何更新和重试

1. 退出课记，运行 `artifacts/desktop/ClassNotes-Setup-0.2.2-x64.exe` 覆盖安装。
2. 打开原来的录音，在「处理记录」找到失败的知识整理任务，点击「重试」；也可在录音详情点击「整理笔记」。
3. 此操作复用已有转录，无须重新识别录音。旧的错误日志和原始响应仍可查看。

数据库格式继续使用 v2，应用标识、安装器 GUID、资料目录及凭证密钥机制沿用原配置。已有录音、转录、笔记历史和设置继续使用。语音识别组件复用 0.2.1，没有重新下载或替换模型的要求。

安装包可手动覆盖更新，配套提供 blockmap 和重新计算摘要的 `latest.yml`。目前没有预设线上更新地址，安装包尚未做代码签名。
