# 课记 0.2.5 · 界面语言与英文说明

在「系统设置 → 界面语言」选择 **简体中文**、**English** 或 **跟随系统**。切换立即生效并自动保存，下次启动继续使用。首次默认为跟随系统，中文系统使用简体中文，其他系统使用英文。

录音库、笔记库、处理记录、设置、上传与转录进度、移动课程、AI 对话操作、常见错误和更新状态支持中英文。桌面退出确认和导入文件夹选择也跟随语言。安装器提供独立的中英文选择，并翻译欢迎说明和退出程序等提示。

语言设置不翻译已有课程名称、录音标题、笔记、转录、AI 回复或 System Prompt；如需模型生成英文笔记，请另行修改系统提示词。第三方服务返回的原始错误信息和原始响应保留原文。

桌面语言保存在用户目录的 `desktop.json`，与更新地址一起保存；网页模式保存在浏览器本地。没有修改数据库结构，数据格式保持 v3。新增 [README.en.md](../../README.en.md)，中英文文档顶部提供切换链接。

退出课记后运行 `artifacts/desktop/ClassNotes-Setup-0.2.5-x64.exe` 覆盖更新，无须先卸载。ASR 组件复用 0.2.3 的已验证构建。
