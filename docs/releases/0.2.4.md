# 课记 0.2.4 · 移动课程

在录音列表右侧点击「移动」，或打开录音后点击标题旁的「移动课程」。选择目标课程，例如从「线性代数」移至「高等数学」，再点击「确认移动」。也可点击「输入新课程」直接建立新的课程归档。

移动会保留原录音、全部转录、笔记正文、版本、确认状态、AI 对话和处理历史，无须重新转录或提取知识。从课程列表发起移动时，当前筛选跟随目标课程，方便继续查看已移动的录音。取消或失败时保留原数据。转录、整理、对话处理或同步有任务排队、运行时，需等待结束再移动。

已同步的笔记保留原 Notion 页面与 Source ID，移动后显示待同步。再次点击「同步到 Notion」会更新同一页面的 Course 属性。移动本身只改变本机归档；再次同步仍会按原有规则写入已确认笔记正文。同步失败或创建结果不确定的记录继续保留原错误和核对流程。

退出课记后运行 `artifacts/desktop/ClassNotes-Setup-0.2.4-x64.exe` 覆盖更新，无须先卸载。数据格式保持 v3，沿用 0.2.3 已验证的 ASR 组件；安装、卸载及资料保留规则保持一致。提供完整安装器、blockmap 和 `latest.yml`，当前通过安装器手动更新，安装器未做代码签名。
