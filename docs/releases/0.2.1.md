# 课记 0.2.1 · 上传与转录进度

## 更新内容

- 上传弹窗显示实际传输比例和已发送大小；传输结束后显示「文件已发送，正在保存录音」，收到后端保存成功的响应后才进入录音详情。
- 录音列表的处理中状态下显示精简转录进度条；录音详情提供完整进度、已识别音频时长和已完成分段数量。
- 转录区分等待、音频转换、准备语音模型、识别、保存和完成。转换与模型准备阶段不编造百分比，实际识别进度按已处理音频位置计算。
- 转录进度在后端成功提交前最多显示 99%，完成后显示 100%。失败保留已有识别结果和进度，重新尝试时使用新任务进度。
- 上传过程中暂时锁定表单，退出桌面程序会提示；更新安装和旧资料导入也会等待上传完成。

桌面版按实际转发的 multipart 字节计量；音频使用复合 Blob 传输，不预先把整个大文件读入 JavaScript 数组。网页模式使用浏览器的上传进度事件。

## 更新安装

退出正在运行的课记，打开 `artifacts/desktop/ClassNotes-Setup-0.2.1-x64.exe`，按照向导覆盖安装即可。无须先卸载旧版。

应用标识、安装器 GUID、用户目录和凭证密钥机制保持原样。数据库格式仍为 v2，本次没有更改业务表；现有录音、转录、笔记历史和设置继续使用。首次使用语音模型的下载行为保持原样。

更新发布目录需要同时提供本版本的安装器、同名 blockmap 和重新计算摘要的 `latest.yml`。当前没有预设线上发布地址，本次提供可手动覆盖安装的完整更新程序。安装包尚未做代码签名。

## 进度数据

Worker 将状态以原子替换方式写到 `data/asr/<任务UUID>/progress.json`。每个识别窗口的原始结果刷盘后才更新已完成时长和分段计数。进度文件写入失败不会中断原有识别和原始结果保存。

Java 在录音查询结果中增加 `transcriptionProgress`：`phase`、`message`、`percent`、`processedMs`、`durationMs`、`completedChunks`、`totalChunks`。`percent: null` 表示当前阶段无法可靠估算进度；数据库任务状态决定最终是否完成。没有进度文件的其他 ASR 服务可继续使用，识别过程中显示等待进度信息。

时间戳仍是音频窗口边界，进度也以窗口完成为单位刷新，不代表词级对齐或剩余耗时估计。
