# 课记 0.2.3 · AI 对话修改与自定义提示词

## 使用方法

打开已生成笔记的录音，在「课堂笔记」工具栏点击 **AI 对话**，直接输入修改要求或问题，例如：

- 保留所有公式和来源时间，精简重复的概念说明。
- 把解题步骤改成编号列表，完整保留易错点。
- 解释这条公式的条件，先不要修改笔记。

发送成功后要求会保存在本机；可以继续对话，关闭再打开可查看最近 40 次记录。AI 实际改动正文时自动生成新版本，在「版本」中可恢复旧内容；只回答问题则保留当前笔记版本。失败时原笔记不变，可以重试这条要求。

长笔记继续按段处理。系统要求模型返回针对原文的精确修改，未涉及的文字保留原样；定位有歧义、修改重叠、输出截断或部分分段失败时不提交本次修改。人工编辑过程中不发送新 AI 要求，后台生成结果也不会覆盖期间产生的人工新版本。AI 改写后的笔记需要重新核对确认才能同步到 Notion。

在 **系统设置 → AI 知识提取 → System Prompt** 编辑系统提示词，然后点击「保存配置」。知识提取和 AI 对话在后续任务开始时使用新提示词，不影响已保存笔记。提示词最多 20000 字符。

**恢复默认** 会立即保存内置课堂提示词，只重置这一项；模型、密钥、分段长度及其他设置保持原样。AI 对话的精确修改格式由程序补充，不必在自定义提示词中编写 JSON 协议。

## 安装更新

退出课记后，运行 `artifacts/desktop/ClassNotes-Setup-0.2.3-x64.exe` 覆盖安装，无须先卸载。录音、转录、笔记历史、凭证和模型缓存继续使用。

本版本将数据格式升级至 **v3**，新增 `note_ai_turns` 保存对话要求、回复及版本关联。升级前备份数据库和 `settings.key`，v2 原有业务表不改写；0.2.2 及更旧程序会拒绝打开 v3 数据，防止错误处理新增任务。

提供安装器、blockmap 和 `latest.yml`，更新清单的输出格式为 v3。尚未配置线上发布站点，当前通过完整安装器手动覆盖更新。安装器未做代码签名。
